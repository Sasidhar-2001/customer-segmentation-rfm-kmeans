# customer-segmentation-rfm-kmeans
A machine learning project that segments customers based on Recency, Frequency, and Monetary values using K-Means clustering and deploys the model via Streamlit.


# Customer Segmentation using RFM & K-Means
This project segments customers into meaningful groups using RFM analysis and K-Means clustering. It is deployed as a Streamlit web application where users can upload data and get segmentation results.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
